# 하루+ · 루틴과 기대수명

매일의 루틴을 체크하면 기대수명이 얼마나 늘어나는지 보여주는 개인용 건강 앱입니다.
CSS·JS·유튜브 영상 목록을 모두 `index.html` 한 파일에 담았고, 기사 여왕 캐릭터
이미지 한 장(`assets/knight-queen.webp`)만 로컬 파일로 함께 배포됩니다. 외부 CDN·폰트
요청은 없고, 기록은 브라우저 localStorage(`routine-app-v1`)에만 저장됩니다.
서버로 보내는 데이터는 없습니다.

## 앱 두 가지

같은 저장소에서 성격이 다른 두 앱을 함께 배포합니다.

| 주소 | 앱 | 무엇이 들어 있나 |
|---|---|---|
| `/` (루트) | **하루+** | 가볍고 단순한 루틴 앱 — 루틴 체크, 기대수명, RPG 기사 동반자, 뜻밖의 랜덤 미션, 코치, 하루 컨디션 한 줄 칩과 기록만으로 읽는 습관 패턴 코칭 |
| `/plus/` | **하루++** | 하루+ 의 기능에 걸음·수면·혈압·식사 간편 기록, 기록 기반 맞춤 안내·미션, Health Connect URL(`?hc_steps=`) 연동을 더한 버전 |

- 하루+ 는 기록을 `routine-app-v1` 에, 하루++ 는 `haru-plus-plus-v1` 에 저장합니다.
  두 앱의 기록은 서로 섞이지 않고, 하루++ 를 처음 열 때 `routine-app-v1` 기록을 한 번만
  복사해 이어받습니다.
- 하루+ 에는 건강·식사·혈압 카드가 없습니다. 그 기록은 하루++ 에서만 다룹니다.

## 하루 컨디션과 습관 패턴 (하루+)

- **한 번 누르는 컨디션**: 첫 화면 위 한 줄에 `⚡ 개운 · 🙂 보통 · 😴 지침` 세 칩이 있습니다.
  하나를 누르면 작은 알약(`😴 지침 ▾`)으로 접히고, 알약을 다시 누르면 바꿀 수 있어요.
  아무것도 누르지 않아도 앱은 그대로 동작하고, 고른 값은 `days[날짜].condition` 에 남습니다.
- **기록만으로 읽는 패턴**: 최근 14일 중 기록이 있는 날이 3일을 넘으면, 새로 물어보지 않고
  이미 쌓인 `days` 만으로 ① 가장 자주 빠지는 루틴 ② 가장 잘 지키는 루틴 ③ 약한 요일
  ④ 주말에 비는 루틴을 계산합니다. 이 패턴과 오늘 컨디션으로
  - 뜻밖의 랜덤 미션의 결(가벼운 호흡·움직임·음악)을 고르고 한 줄 이유를 보여주며,
  - 코치(닥터 튼튼·마인드 메이·마에스트로 리·아키텍트 진)와 기사 동반자의 대사를 실제 기록에 맞춰 바꿉니다.
- 계산은 모두 브라우저 안에서만 이뤄지고, 어떤 값도 서버로 나가지 않습니다.

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 하루+ 본체 (HTML + CSS + JS 한 파일) |
| `plus/index.html` | 하루++ 본체 (건강·식사·Health Connect 포함) |
| `plus/manifest.webmanifest` | 하루++ PWA 매니페스트 |
| `assets/knight-queen.webp` 외 | RPG 동반자 초상 3종 (여왕·왕·아기 기사) |
| `manifest.webmanifest` | 하루+ PWA 매니페스트 (홈 화면에 추가 시 독립 앱 창으로 실행) |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |
| `icon-maskable-512.png` | Android 마스커블 아이콘 |
| `apple-touch-icon.png` | iOS 홈 화면 아이콘 |
| `icon.svg` | 벡터 아이콘 |
| `share/index.html` | 지인 공유용 소개 페이지 (`/share/` — 상대 경로로 앱·자산 참조) |
| `android-hc-bridge/` | Health Connect 값을 `?hc_steps=` 로 넘기는 안드로이드 미니 앱 (하루++ 용) |

## 지인 공유 페이지

`https://lukekim777.github.io/luke-routine-app/share/` 는 앱을 지인에게 소개하는
한 페이지짜리 랜딩 페이지입니다. 본체(`index.html`)는 그대로 `/` 에 남아 있고,
공유 페이지는 `../` 와 `../assets/knight-queen.webp` 같은 상대 경로만 써서
로컬 파일로 열어도 GitHub Pages에서도 똑같이 동작합니다. 기록은 공유 페이지가
아니라 앱 본체의 localStorage에만 남습니다.

## 특징

- 기상·취침·근력 운동·영어 공부·주말 악기 연습 등 6가지 루틴 체크
- 체크할 때마다 기대수명이 늘어나는 계산기 (동기부여용 추정 모델)
- 매일 바뀌는 오늘의 도전, 연속 달성 기록, 최근 7일 히스토리
- ⚔️ RPG 레벨·EXP: 루틴 체크로 EXP가 쌓이고(보통 +20, 힘든 루틴 +25),
  레벨과 칭호(견습 기사 → 수호 기사 → 성기사 → 빛의 기사단장 → 왕국 수호자 …)가 오릅니다
- 🎲 오늘의 뜻밖의 랜덤 미션: 하루 하나, 26가지 1분 미션 중 하나가 열리고
  완료하면 +50 EXP와 기대수명 +10분. `↻ 다른 미션`으로 다시 고를 수 있습니다
- 기사 여왕 동반자 카드: 숨쉬는 듯한 초상, 금빛 광택·오라·반짝이 애니메이션,
  오늘의 진행과 컨디션·최근 기록에 맞춰 달라지는 대사
- 평일·토요일·일요일 기상 시간을 따로 둡니다
- 한국어 / English / Français, 라이트·다크 테마, 모바일 화면 기준 UI
- 오프라인에서도 동작 (모든 자원이 이 저장소 안에 있음)
