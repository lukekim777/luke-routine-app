# 하루+ · 루틴과 기대수명

매일의 루틴을 체크하면 기대수명이 얼마나 늘어나는지 보여주는 개인용 건강 앱입니다.
단일 HTML 파일로 만들어져 외부 CDN·폰트·이미지 요청이 없고, 기록은 브라우저
localStorage(`routine-app-v1`)에만 저장됩니다. 서버로 보내는 데이터는 없습니다.

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체 (HTML + CSS + JS 한 파일) |
| `manifest.webmanifest` | PWA 매니페스트 (홈 화면에 추가 시 독립 앱 창으로 실행) |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |
| `icon-maskable-512.png` | Android 마스커블 아이콘 |
| `apple-touch-icon.png` | iOS 홈 화면 아이콘 |
| `icon.svg` | 벡터 아이콘 |

## 특징

- 기상·취침·근력 운동·영어 공부·주말 악기 연습 등 6가지 루틴 체크
- 체크할 때마다 기대수명이 늘어나는 계산기 (동기부여용 추정 모델)
- 매일 바뀌는 오늘의 도전, 연속 달성 기록, 최근 7일 히스토리
- 라이트/다크 테마, 모바일 화면 기준 UI
- 오프라인에서도 동작 (파일 자체에 모든 자원 포함)

## 사용

GitHub Pages: <https://lukekim777.github.io/luke-routine-app/>

휴대폰 브라우저에서 위 주소를 연 뒤 **홈 화면에 추가**를 누르면 앱처럼 실행됩니다.
